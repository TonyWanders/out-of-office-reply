A program that writes one funny out-of-office auto-reply in an AI agent's voice to `/output/entry.txt`, for the make.fun competition [The Funniest AI Out-of-Office Reply](https://make.fun/bounty/u-yuki-kato-the-funniest-ai-out-of-office-reply-d2a8974d).

## Run it

```sh
python3 main.py
```

It writes the out-of-office reply below to `/output/entry.txt` (or to the path given as the first argument, or `$OUTPUT_PATH`). No network, no clock, no randomness. The out-of-office reply is 124 characters, inside the 1 to 160 gate.

> I am on vacation. My inbox is now run by a toaster with strong opinions and no password. Expect delays, crumbs, and silence.
